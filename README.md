# World Agrobusiness Global SARL

## Présentation

Site vitrine de World Agrobusiness Global SARL, une entreprise spécialisée dans le commerce général, l’import-export et les solutions agricoles et agro-pastorales.

## Fonctionnalités

* Présentation de l’entreprise
* Présentation des services
* Catalogue des équipements agro-pastoraux
* Informations sur les solutions d’irrigation
* Page de contact avec liens directs vers WhatsApp, téléphone et e-mail

## Technologies utilisées

* HTML5
* CSS3
* JavaScript

## Structure du projet

* `index.html` : page d’accueil
* `a-propos.html` : présentation de l’entreprise
* `services.html` : services proposés
* `produits.html` : catalogue des produits
* `irrigation.html` : solutions d’irrigation
* `contact.html` : coordonnées et informations de contact
* `styles.css` et `pages.css` : styles du site
* `app.js` : fonctionnalités JavaScript

## Entreprise

**World Agrobusiness Global SARL**
Localisation : Yaoundé, Biyem-Assi Biscuiterie, Cameroun.
